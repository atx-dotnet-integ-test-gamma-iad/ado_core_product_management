================================================================================

SQL Syntax Transformations:
1. Table Names: Products → products, ProductHistory → producthistory, 
   ProductStats → productstats
2. Column Names: All converted to lowercase (ProductId → productid, etc.)
3. Functions: GETDATE() → CURRENT_TIMESTAMP

5. Transactions: BEGIN TRANSACTION/COMMIT → BeginTransactionAsync()/CommitAsync()

1. using Microsoft.Data.SqlClient → using Npgsql
2. SqlConnection → NpgsqlConnection

Window Functions and CTEs:

- CTE syntax identical
