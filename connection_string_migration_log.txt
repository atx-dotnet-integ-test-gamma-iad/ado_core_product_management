==================================================================================
PARAMETER MAPPING DETAILS
==================================================================================

SQL Server Parameter → PostgreSQL Parameter:

1. Server=localhost → Host=localhost
   - SQL Server uses "Server" parameter
   - PostgreSQL uses "Host" parameter
   - Value unchanged (localhost)

2. Database=ProductManagement → Database=ProductManagement
   - Parameter name and value unchanged
   - Both databases use same "Database" parameter

3. Trusted_Connection=True → Username=postgres;Password=postgres
   - SQL Server: Windows Authentication via Trusted_Connection
   - PostgreSQL: Explicit username/password authentication
   - Default PostgreSQL user: "postgres"
   - Default password: "postgres" (SHOULD BE CHANGED FOR PRODUCTION)

4. MultipleActiveResultSets=true → REMOVED
   - SQL Server specific feature
   - Not applicable to PostgreSQL
   - PostgreSQL handles multiple result sets differently

5. TrustServerCertificate=True → REMOVED
   - SQL Server SSL/TLS certificate validation bypass
   - Not needed for local development
   - For production, use: SSL Mode=Require or SSL Mode=Prefer

6. (Added) Port=5432
   - Default PostgreSQL port
   - Explicitly specified for clarity
   - Can be omitted (defaults to 5432)
