POSTGRESQL CONNECTION STRING FORMAT:
====================================

Standard Npgsql Connection String Parameters:
----------------------------------------------
Required:
- Host or Server: Database server hostname or IP
- Database: Database name to connect to
- Username or User ID: PostgreSQL user account
- Password: User password

Optional Common Parameters:
- Port: PostgreSQL port (default: 5432)
- Timeout: Connection timeout in seconds
- Pooling: Enable/disable connection pooling (default: true)
- MinPoolSize: Minimum connection pool size
- MaxPoolSize: Maximum connection pool size
- SSL Mode: SSL/TLS mode (Disable, Prefer, Require, etc.)
- Application Name: Application identifier for monitoring

Current Configuration Uses:
- Host=localhost (standard)
- Database=postgres (default PostgreSQL database)
- Username=postgres (default superuser)
- Password=postgres (matches username - typical dev setup)

SQL SERVER VS POSTGRESQL FORMAT COMPARISON:
============================================

SQL Server Connection String (NOT USED):
-----------------------------------------
Example: "Server=localhost;Database=MyDB;Integrated Security=true;TrustServerCertificate=true"
or: "Server=localhost;Database=MyDB;User ID=sa;Password=MyPassword"

Key Differences:
- Server= instead of Host=
- User ID= instead of Username=
- Integrated Security for Windows auth
- TrustServerCertificate for SSL handling
- Different parameter names and options

PostgreSQL/Npgsql Connection String (CURRENT):
-----------------------------------------------
Example: "Host=localhost;Database=MyDB;Username=myuser;Password=mypass"

Key Features:
- Host= for server specification
- Username= for authentication
- Password= for credentials
- Port= optional (defaults to 5432)
- Connection pooling enabled by default
