CRITICAL TRANSFORMATION DETAILS
======================================================================================

1. Schema Transformation
   - All database objects transformed: dbo → productmanagement_dbo
   - This is a DMS-level transformation and is intentional
   - Ensures consistency with PostgreSQL database schema
   - Must be respected in all SQL statements

2. Transaction Management
   - Moved from SQL (BEGIN TRANSACTION/COMMIT) to C# code
   - Using NpgsqlConnection.BeginTransactionAsync()
   - All transaction blocks have proper error handling (try/catch/rollback)
   - Maintains ACID properties across multiple SQL statements

3. SCOPE_IDENTITY() Replacement
   - SQL Server: SET @NewProductId = SCOPE_IDENTITY()
   - PostgreSQL: INSERT ... RETURNING productid
   - C# code captures returned value using ExecuteScalarAsync()

4. GETDATE() Replacement
   - SQL Server: GETDATE()
   - PostgreSQL: CURRENT_TIMESTAMP or clock_timestamp()
   - CURRENT_TIMESTAMP: Transaction start time
   - clock_timestamp(): Current system time

5. Column Name Casing
   - PostgreSQL uses lowercase by default for unquoted identifiers
   - All column references updated: ProductId → productid, Name → name, etc.
   - MapProductFromReader() updated to use lowercase column names

6. Window Functions
   - All window functions preserved correctly:
     * AVG() OVER()
     * COUNT() OVER()
     * LAG() OVER()
     * RANK() OVER()
     * PERCENT_RANK() OVER()
     * MIN() OVER()
     * MAX() OVER()

7. NULL Handling
   - ORDER BY clauses enhanced with NULLS FIRST
   - PostgreSQL best practice for explicit null ordering
