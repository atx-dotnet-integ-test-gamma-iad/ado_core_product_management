Key Manual Conversion Patterns Applied:

1. Date/Time Functions:
   - GETDATE() -> CURRENT_TIMESTAMP
   
2. Identity Columns:
   - IDENTITY(1,1) -> SERIAL or GENERATED ALWAYS AS IDENTITY
   
3. Data Types:
   - nvarchar(N) -> VARCHAR(N)
   - varchar(N) -> VARCHAR(N) (compatible)
   - bit -> BOOLEAN
   - datetime -> TIMESTAMP
   - int -> INTEGER (compatible)
   - decimal(P,S) -> DECIMAL(P,S) (compatible)
   
4. Sequence Functions:
   - SCOPE_IDENTITY() -> RETURNING clause or lastval()
   
5. Transaction Control:
   - BEGIN TRANSACTION -> BEGIN
   - COMMIT -> COMMIT
   - ROLLBACK -> ROLLBACK
   
6. Schema Notation:
   - [dbo].[TableName] -> TableName (removed brackets and schema)
   - [ColumnName] -> ColumnName (removed brackets)
   
7. Conditional Table Operations:
   - IF EXISTS (SELECT * FROM sys.objects...) DROP TABLE -> DROP TABLE IF EXISTS
   - IF NOT EXISTS (SELECT * FROM sys.databases...) CREATE DATABASE -> CREATE DATABASE IF NOT EXISTS (not directly supported, requires different approach)
   
8. System Functions:
   - SYSTEM_USER -> CURRENT_USER
   - @@ROWCOUNT -> ROW_COUNT (in trigger context)
   
9. Triggers:
   SQL Server:
     CREATE TRIGGER ... AFTER INSERT, UPDATE, DELETE AS
     BEGIN
       -- Use 'inserted' and 'deleted' tables
     END
     
   PostgreSQL:
     CREATE FUNCTION trigger_func() RETURNS TRIGGER AS $$
     BEGIN
       -- Use NEW and OLD records, check TG_OP
       RETURN NEW/OLD;
     END;
     $$ LANGUAGE plpgsql;
     
     CREATE TRIGGER ... AFTER INSERT OR UPDATE OR DELETE
     FOR EACH ROW EXECUTE FUNCTION trigger_func();

10. Stored Procedures:
    SQL Server:
      CREATE OR ALTER PROCEDURE proc_name @param TYPE AS
      BEGIN
        -- body
      END
      
    PostgreSQL:
      CREATE OR REPLACE FUNCTION proc_name(param TYPE)
      RETURNS return_type AS $$
      BEGIN
        -- body
        RETURN value;
      END;
      $$ LANGUAGE plpgsql;

11. Window Functions:
    - AVG() OVER() - Compatible
    - COUNT() OVER() - Compatible
    - LAG() OVER() - Compatible
    - RANK() OVER() - Compatible
    - PERCENT_RANK() OVER() - Compatible
    - All window functions tested are compatible between SQL Server and PostgreSQL

12. Common Table Expressions (CTEs):

    - Multiple CTEs with comma separation: compatible
    - Recursive CTEs: compatible (both use WITH RECURSIVE)
