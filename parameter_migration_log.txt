================================================================================
PARAMETERS.ADDWITHVALUE COMPATIBILITY
================================================================================

Method: Parameters.AddWithValue(string parameterName, object value)

SQL Server (Microsoft.Data.SqlClient):
- Supported: ✓ Yes
- Behavior: Infers SQL Server data type from .NET type

Npgsql (PostgreSQL):
- Supported: ✓ Yes
- Behavior: Infers PostgreSQL data type from .NET type
- Same ADO.NET interface

Compatibility Assessment: ✓ FULLY COMPATIBLE

Note: While AddWithValue is convenient, for production applications with
      performance requirements, explicitly typed parameters (using NpgsqlParameter
      with NpgsqlDbType) may provide better performance by avoiding type inference.

Alternative (if needed for performance):
var parameter = new NpgsqlParameter("@ParamName", NpgsqlDbType.Integer) { Value = paramValue };
command.Parameters.Add(parameter);
