## Tool Limitations Identified

Based on retry attempts, the SQL Equivalency tool has the following limitations:

1. **CTEs with Window Functions**: Cannot validate queries containing:
   - AVG() OVER()
   - COUNT() OVER()
   - LAG() OVER()
   - RANK() OVER()
   - PERCENT_RANK() OVER()
   - MIN()/MAX() OVER()

2. **DML Statements**: Cannot validate INSERT, UPDATE, DELETE statements even with simple structure

3. **Schema-Qualified Names**: Has difficulty with schema-qualified table names (e.g., productmanagement_dbo.products)

4. **Multi-Statement Transactions**: Cannot validate transaction blocks with multiple statements

5. **Complex Queries**: Z3SqlSolverVerifier cannot handle production-level query complexity
